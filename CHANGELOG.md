# Changelog

All notable changes to this project are recorded here. Entries from 0.3.0
onwards are generated by release-plz from the conventional-commit history
when it opens a release PR; 0.1.0 and 0.2.0 were written retrospectively
from the same history.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-08-09

### Added

- Show a one-time hint when speedwalking or a trigger first fires
- Reuse the new-profile wizard as /newprofile after startup
- Add /connect <profile> to join a character to a running instance

### Fixed

- Refuse to save a duplicate-pattern or no-op trigger
- Cap the new-profile wizard's name field at 32 characters
- Stop profile rule errors from doubling their own backticks

## [0.1.0] - 2026-08-09

### Added

- Initial scaffold with architecture docs and protocol seams
- Implement M0 walking skeleton
- Implement M1 proper Telnet
- Implement M2 STelnet
- Implement M3 config & profiles
- Implement M4 automation engine
- Implement M5 MCCP
- Bound MCCP inflate and reset the decoder on restart
- Implement M6 GMCP + MSDP
- Implement M7 multi-character sessions
- Recall sent commands with Up/Down, per session (§11.3)
- Add an F1 help overlay and /help, rendered from the live keybinds (§11.2)
- Tint a character's pane border and tab from its profile color
- Auto-login from a profile, with the password in the OS keyring (§10.1)
- Add --forget-password to delete a profile's keyring password
- Offer to save a typed login password to the keyring (§13)
- Gate rules on `when:` conditions (§7.6)
- Host Lua scripts behind a `ScriptHost` trait (§7.4)
- Call script functions from YAML rules (§7.4)
- Add a JavaScript engine and a shared conformance suite (§7.4)
- Publish peer state snapshots and read them as `${@peer.key}` (§7.5)
- Give scripts peer state and `mud.on_peer` subscriptions (§7.5)
- Add `mud.timer` and cross-session `:echo` to the script API (§7.4/§7.5)
- Recolour matched text with rule highlights (§7.7)
- Add scrollback navigation with a configurable buffer size (§8/§11.5)
- Reconnect with capped exponential backoff (§5)
- Show round-trip latency in the pane title (§11)
- Make the channel column resizable (§11.4)
- Add per-profile disk logging (§8)
- Add desktop notifications for unfocused triggers (§7.8)
- Add .3n2e speedwalk path expansion (§7.9)
- Add in-TUI new-profile form on first run (§15)
- Add an in-client profile editor and scrollback-to-trigger picker (§10.2)
- Add cargo-dist release automation for tagged builds

### Fixed

- Send a bare Enter to the server instead of swallowing it
- Add a space between the unread dot and its count
- Cap MSDP nesting depth and remove Lua's coroutine escape hatch
- Reject traversal in profile module names, restrict private file perms
- Use local time instead of UTC for channel pane timestamps
- Expire GMCP array entries instead of merging them forever
- Expire MSDP array entries too, sharing the GMCP mechanism
- Cancelling the first-run wizard no longer exits the whole client
- Put the full disconnect reason in scrollback, not just the title
- Carry a line's origin from the session, not just the hub
- Stop server data reaching the terminal as control bytes (§13)

### Performance

- Render the scrollback viewport instead of the whole buffer
- Cache each retained line's plain-text projection

### Changed

- Replace the crate-wide dead_code allowance with targeted ones
- Retain arrival time and origin per scrollback line
